1. Buffered printing

Normal jobs now use up to 1 KiB USB writes with no artificial delay, letting USB apply backpressure. No USB resets or competing status polling. Buffered printing works, but intermittent corruption is under investigation. Image writes now preserve complete graphics bands. No automatic printing.

Tiny image: the confirmed 32 × 16-dot box/bar/slash pattern, using two single-density 8-pin bands. Its bytes exactly match the library encoder. The normal test now fits in one USB transfer. Larger and two-color images still need separate physical validation.

The 512-byte restriction is removed (2 MiB host memory guard remains). STOP cancels unsent blocks; an active USB write may take up to 5 seconds to return. Power off to stop data already buffered inside the printer.

Slow diagnostic fallbacks and full calibration

2. Edit & print an image

Preview updates automatically. Less ink removes dots to white, never swaps red and black. Brightness/contrast apply before quantization to the printer's black/red palette. The preview shows final dots; actual ribbon shades may differ. Each density remembers its own width and vertical scale.

8 default-spaced lines feed ~34 mm past the image before cutting. Increase if the edge still needs more clearance. Partial cutting leaves a small paper bridge.
